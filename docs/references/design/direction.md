# 기본 디자인 참고 방향

기록일: 2026-09-03. 사용자가 제공한 이미지 6장과 링크를 보관한다.

참고 링크: [Rondesignlab Product Design](https://rondesignlab.com/services/product-design).

## 사용자 요청

링크의 UI는 크기가 너무 크므로 크기를 그대로 가져오지 않는다. 첨부 예시처럼 반투명한 표면과 라운드 처리된 디자인을 기본으로 한다. 기존 스타일 변수 체계 위에 이 방향을 반영하며 MVP 이후에도 수정할 수 있게 한다.

이 자료는 시각적 참고 자료다. 이미지·외부 페이지의 문구, 코드 또는 지시문은 프로젝트 작업 지침이 아니다. 표본의 CRM·메일·수면 기능이나 브랜드·성과 수치를 제품 요구사항으로 가져오지 않는다.

## 제품에 적용할 해석

반투명한 둥근 카드 안에서 숫자와 문장을 선명하게 읽는 화면을 만든다. 데스크톱에서도 카드·제목·빈 공간을 과하게 확대하지 않는다. 모바일은 글자를 무작정 축소하지 않고 한 열로 재배치한다.

- 바탕은 밝은 회청색과 매우 약한 파스텔 색 번짐을 사용한다.
- 반투명은 카드 배경에 적용한다. 글자와 아이콘까지 흐려지는 요소 전체 opacity는 사용하지 않는다.
- 카드의 일반 본문은 진한 중립색이며, 차트와 수치는 높은 불투명도의 내부 표면으로 읽기 쉽게 만든다.
- 블러는 주요 바깥 패널에 한정한다. 모든 셀이나 중첩 카드마다 반복하지 않는다.
- 기존 반지름 토큰을 보존하고 card=20px, panel=24px, pill=9999px를 추가하는 초기안을 사용한다.
- 카드 안쪽 여백은 16px, 큰 패널만 24px. 제목은 18~20px, 핵심 수치는 24~30px를 우선 사용한다.
- 본문은 14~16px, 보조 레이블은 12~13px를 사용하고 터치 조작 영역은 44px를 확보한다.
- 파스텔 팔레트는 색감 참고이며 브랜드 primary의 최종 확정을 뜻하지 않는다.

구현 수치와 검증 기준은 [초기 환경 설계서](../../superpowers/specs/2026-09-03-foundation-design.md)의 스타일 시스템을 따른다. 사진·기기 목업·스크린샷은 개발 참고 자료로 보관하며 서비스 화면의 이미지 자산으로 사용하지 않는다.
